# PSU48-800 — БП 220 В AC → 48 В DC, 800 Вт

Проект импульсного блока питания (PFC + LLC), разрабатывается в KiCad 10.

- `JOURNAL.md` — инженерный журнал (этапы, решения, изменения).
- `docs/SPEC.md` — техническое задание.
- `docs/DESIGN.md` — расчёт топологии.
- `kicad/` — проект KiCad (схема, плата, библиотеки).
- `tools/` — скрипты генерации и проверки (Python, bundled с KiCad).
- `production/` — производственные файлы (Gerber, drill, BOM, CPL, PDF).

Сборка проекта (генерация схемы/платы) и выпуск — см. журнал, этапы работ.
