# Техническое задание — PSU48-800

| Параметр | Значение |
|---|---|
| Входное напряжение | 176…264 В AC, 50/60 Гц (номинал 220 В) |
| Выходное напряжение | 48,0 В DC ±3 % (46,6…49,4 В) |
| Выходной ток / мощность | 0…16,7 А / 800 Вт |
| КПД | ≥ 93 % при 220 В, полной нагрузке |
| Коэффициент мощности | ≥ 0,99 при 220 В |
| THD входного тока | < 10 % |
| Пульсации выхода | ≤ 1 % (≤ 480 мВ п-п) |
| Время сохранения выхода | ≥ 20 мс при 800 Вт |
| Шина PFC | 400 В ±10 В |
| Напряжение гальванической развязки | вход — выход ≥ 3,75 кВ (усиленная изоляция, II класс) |
| Защиты | OCP, OVP, SCP (автостарт), UVLO, перегрев, разряд шины |
| Сигналы | PG (Power Good), Remote ON/OFF (TTL/сухой контакт) |
| Охлаждение | принудительное, вентилятор 12 В 60×25 мм |
| Габариты платы | 280 × 90 мм |
| Высота сборки | ≤ 40 мм (в сборе с корпусом) |
| Установка | 4 отверстия Ø3,2 под М3 |
